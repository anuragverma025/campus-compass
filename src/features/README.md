# Features Directory

This directory hosts self-contained feature modules for Campus Compass.
Implementation begins in **Phase 2**.

## Directory Mapping & Phase 2 Ownership

- **`planner/`**: Academic deadlines, assignment boards, exam counters.
  - Assigned to: Member 1 & Member 2
- **`calendar/`**: Timetable schedule, recurring classes, lab sessions.
  - Assigned to: Member 2 & Member 3
- **`opportunities/`**: Internships, scholarships, hackathon listings.
  - Assigned to: Member 3 & Member 4
- **`placement/`**: DSA question tracking, revision reminders, interview checklists.
  - Assigned to: Member 1 & Member 4
- **`dashboard/`**: Unified dashboard aggregating widgets from the above modules.
  - Assigned to: Full Team integration in Phase 2
